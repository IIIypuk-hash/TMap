# Карта угроз

Демонстрационное веб-приложение: интерактивная карта террористических инцидентов
на территории РФ, 1991–2026.

## Возможности

- Карта России (Leaflet + OpenStreetMap) с маркерами инцидентов
- Клик по маркеру — карточка с датой, типом, регионом, числом жертв и статусом расследования
- Фильтры по регионам и типу инцидента
- Диапазон лет (двойной слайдер)
- «Режим хронологии»: слайдер и кнопка воспроизведения — инциденты появляются
  по годам (накопительно или только текущий год)

## Данные

Набор данных в [`data.js`](data.js) собран вручную по открытым источникам (СМИ,
справочные материалы) и носит демонстрационный характер: цифры жертв —
ориентировочные, статусы расследований упрощены, координаты приближены к
населённому пункту. Для точных и юридически значимых сведений используйте
официальные источники (СК РФ, судебные акты, специализированные базы вроде
Global Terrorism Database).

## Запуск

Приложение полностью статическое (HTML/CSS/JS), достаточно любого веб-сервера:

```bash
python -m http.server 8642
```

и открыть `http://localhost:8642`. Для тайлов карты (OpenStreetMap) и
библиотеки Leaflet нужен доступ в интернет.
